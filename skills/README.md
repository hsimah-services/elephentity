# Elephentity agent skills

Skills teach a coding agent to work with Elephentity. Each is a short `SKILL.md` (loaded when
its description matches the task) plus `reference/` files that are read **only when the
`SKILL.md` points at them**, so an agent pays for the detail it needs and nothing else.

## Pick by task

| You are asked to… | Skill | Start at |
|---|---|---|
| work in a project that has `eleph.json` or `spec/`; add a field, edge, action; fix a failing `eleph` command | [`eleph`](eleph/SKILL.md) | "Orient yourself first" |
| turn a ticket, document or conversation into spec YAML | [`eleph-spec-author`](eleph-spec-author/SKILL.md) | "Interview before you write" |
| generate a new language or file type from the spec | [`eleph-add-builder`](eleph-add-builder/SKILL.md) | "Decide first" |
| support a new database or store (`storage.driver`) | [`eleph-add-adaptor`](eleph-add-adaptor/SKILL.md) | "Nearest examples" |
| expose entities over a new API (`integrations:`) | [`eleph-add-integration`](eleph-add-integration/SKILL.md) | "How the spec learns your keys" |

The first two are for **using** Elephentity in an application. The last three are for
**extending** it and assume a checkout of the framework repository; `eleph-add-adaptor` and
`eleph-add-integration` both build on `eleph-add-builder`.

## Installing

Into an application, for the two usage skills:

```bash
git clone --depth 1 https://github.com/hsimah-services/elephentity.git /tmp/elephentity-skills
cp -r /tmp/elephentity-skills/skills/eleph /tmp/elephentity-skills/skills/eleph-spec-author .claude/skills/
```

Agents that do not read `.claude/skills` (Codex, Cursor and others) can be pointed at the
same files from the project's `AGENTS.md`:

```markdown
## Elephentity
This project's entities are defined by specs in `spec/` and compiled by `eleph`.
Never edit files marked `GENERATED BY Elephentity`; change the spec and run
`eleph validate && eleph generate && eleph check`.
Read `.claude/skills/eleph/SKILL.md` before changing a spec or a generated contract.
```

Working in the framework itself needs no install: `.claude/skills` in this repository links
to this directory. To add a skill, keep `SKILL.md` short, put detail one hop away in
`reference/`, list it above, and link it from the relevant doc in `docs/README.md`.
